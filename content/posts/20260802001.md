部署个人图片图床可以==通过使用开源程序如 [兰空图床 (Lsky Pro)](https://www.cnblogs.com/aixing/p/16210598.html) 或 [EasyImage](https://zhuanlan.zhihu.com/p/1890572588754920162)，配合 Docker 容器或云端对象存储（如阿里云 OSS、腾讯云 COS）快速完成==。 [[1](https://zhuanlan.zhihu.com/p/1890572588754920162), [2](https://www.cnblogs.com/aixing/p/16210598.html), [3](https://zhuanlan.zhihu.com/p/1890869896788829638), [4](https://developer.aliyun.com/article/1720308)]

部署方式选择

- **服务器 Docker 部署**：使用 Docker 镜像快速搭建，数据完全掌握在自己手中。

- **云端存储/免费图床**：结合 GitHub 仓库 或兰空图床对接第三方对象存储，省去维护服务器硬盘的麻烦。
